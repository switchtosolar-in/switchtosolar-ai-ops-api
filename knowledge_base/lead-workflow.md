# Lead Workflow

The platform generates leads when users request quotes for solar installation.

Lead lifecycle:

1. User submits solar request
2. Lead is assigned to installers
3. Installers can unlock the lead
4. Installer contacts the user
5. Lead is tracked based on SLA status

SLA buckets include:

- HOT (0–6 hours)
- WARM (6–12 hours)
- COLD (12–24 hours)
- DYING (24–36 hours)
- OVERDUE (36+ hours)

The system prioritizes fast response and tracks installer behavior.
