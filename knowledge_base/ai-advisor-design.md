# AI Advisor Design

## Purpose

The AI Advisor is a report-aware conversational assistant in the SwitchToSolar platform.

Its purpose is to help users understand their generated solar report through natural-language questions and answers.

The Advisor is not a generic chatbot. It is designed to answer questions that are directly related to the user's solar report, rooftop solar concepts, savings, system size, payback period, rooftop feasibility, bill impact, and other report-specific recommendations.

## Runtime Behavior

The AI Advisor works after a solar report has already been generated.

High-level runtime flow:

1. User opens a generated solar report.
2. User asks a question in the AI Advisor interface.
3. The frontend sends the question and report token to the backend.
4. The backend validates the report token.
5. The backend loads the saved solar report.
6. The backend extracts relevant report fields.
7. The backend builds a structured prompt using report context.
8. The LLM generates a response grounded in the report.
9. The response is returned to the frontend.
10. Request metadata may be logged for observability.

## Context Used

The AI Advisor uses structured solar report context.

Common context fields may include:

- monthly electricity bill
- estimated monthly units
- recommended solar system size
- ideal solar system size
- rooftop limitation or capacity constraints
- solar generation estimate
- monthly savings
- annual savings
- final investment
- subsidy estimate
- payback period
- lifetime savings
- bill after solar
- rooftop support information
- environmental impact estimates

The Advisor should use the report as the main source of truth.

## Supported Questions

The AI Advisor can answer questions such as:

- Why is this system size recommended?
- Why is the ideal system size different from the recommended size?
- Why will my electricity bill not become zero?
- What does payback period mean?
- How are my monthly savings estimated?
- Is my rooftop enough for the recommended system?
- What does solar generation mean?
- How should I understand the investment and savings shown in my report?
- What does the report say about my rooftop feasibility?
- What is the meaning of annual savings or lifetime savings?

## Scope Rules

The AI Advisor should stay within the solar report and related rooftop solar concepts.

Allowed scope:

- explaining report values
- explaining solar sizing
- explaining savings and payback
- explaining rooftop feasibility
- explaining solar generation
- explaining bill impact
- explaining basic rooftop solar concepts connected to the report

Out-of-scope topics:

- recommending a specific installer
- comparing solar vendors
- comparing panel brands
- giving unrelated financial advice
- answering general unrelated questions
- inventing report values that are not present
- making unsupported claims about installation quality or pricing

If a question is outside scope, the Advisor should return a safe response and redirect the user back to report-related solar guidance.

## Difference from AI Explainer

The AI Advisor is conversational.

It can answer user questions about the report and maintain limited conversational context.

The AI Explainer is section-specific.

It explains one selected report section or metric at a time, such as system size, savings, coverage, payback period, or rooftop feasibility.

The Advisor is better for open report-related questions.

The Explainer is better for focused explanations of a specific report value.

## Design Principles

The AI Advisor follows these design principles:

- report-grounded responses
- scoped solar guidance
- simple user-friendly language
- refusal for unsupported questions
- no invented calculations
- no installer or brand recommendations
- backend-controlled prompt construction
- structured context injection
- observable AI execution

## Important Notes

The AI Advisor should not calculate the official solar report values.

The solar report values are generated by deterministic backend logic.

The Advisor explains, contextualizes, and clarifies the report.

This separation keeps business-critical calculations controlled while using AI to improve user understanding.
