# SwitchToSolar Overview

SwitchToSolar is a rooftop solar platform built to help users understand solar installation, estimate savings, and connect with installers.

The platform allows users to:

- Generate a solar report based on their electricity usage
- Understand system size recommendations in kW
- View estimated monthly savings and payback period
- Compare solar installers
- Request quotes from selected installers

The backend is built using Node.js and Express, and the frontend is built using Next.js.

The system also includes AI features such as AI Advisor and AI Explainer to help users understand their solar reports.
