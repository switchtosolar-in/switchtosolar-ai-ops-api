# SwitchToSolar Overview

## Purpose

SwitchToSolar is a rooftop solar platform built to help homeowners understand solar feasibility, estimate savings, generate solar reports, and connect with solar installers.

The platform focuses on making rooftop solar easier to understand for users who may not know how system size, savings, payback period, rooftop feasibility, subsidy, or installer selection works.

## Core User Capabilities

Users can use SwitchToSolar to:

- generate a solar report based on electricity usage
- understand recommended solar system size
- estimate monthly and annual savings
- understand payback period
- review expected investment and subsidy impact
- understand rooftop feasibility
- learn solar concepts in simple language
- compare or discover solar installers
- request solar quotes

## Solar Report

The solar report is one of the main outputs of the platform.

A solar report may include:

- monthly electricity bill
- estimated monthly electricity usage
- recommended system size
- ideal system size
- rooftop-supported system size
- solar generation estimate
- monthly savings
- annual savings
- final investment
- subsidy estimate
- payback period
- lifetime savings
- bill after solar
- rooftop feasibility
- environmental impact
- delay-loss estimate

The solar report values are generated by deterministic backend logic.

AI is used to explain, contextualize, and answer questions about the report. AI should not invent or replace the official report calculations.

## Main Platform Layers

SwitchToSolar uses a multi-service architecture.

Main layers include:

- Next.js frontend
- Node.js / Express backend
- MSSQL / Azure SQL database
- FastAPI AI Ops service
- PostgreSQL + pgvector for AI retrieval workflows

## Frontend Layer

The frontend handles user and admin interaction.

Frontend responsibilities include:

- public website pages
- solar report form
- solar report display
- AI Advisor user interface
- AI Explainer user interface
- installer discovery pages
- admin dashboard interface
- partner dashboard interface

The frontend should not directly access databases, vector retrieval systems, or LLM providers.

## Backend Layer

The backend acts as the main governance and orchestration layer.

Backend responsibilities include:

- API routing
- authentication and authorization
- solar report generation
- deterministic solar calculations
- lead workflows
- installer workflows
- report token handling
- AI Advisor orchestration
- AI Explainer orchestration
- AI request logging
- AI feedback handling
- protected admin operations

The backend owns trusted business logic and controlled access to platform data.

## AI Ops Layer

The FastAPI AI Ops service supports internal AI-assisted workflows.

AI Ops responsibilities include:

- Retrieval-Augmented Generation
- knowledge base ingestion
- chunking
- embedding generation
- semantic retrieval
- PostgreSQL + pgvector search
- intent routing
- operational AI tooling
- prompt construction
- LLM execution
- query logging
- AI observability

AI Ops is designed as a dedicated AI systems layer separate from the main product backend.

## AI Features

SwitchToSolar includes several AI-assisted workflows.

### AI Advisor

The AI Advisor is a report-aware conversational assistant.

It helps users ask questions about their generated solar report.

### AI Explainer

The AI Explainer provides focused explanations for specific report sections or metrics.

It helps users understand values such as system size, savings, payback period, rooftop support, and bill impact.

### Admin AI Ops Assistant

The Admin AI Ops Assistant supports internal knowledge and operational workflows.

It can answer platform knowledge questions using retrieval and answer operational questions using controlled backend tools.

## Deterministic and AI Separation

SwitchToSolar separates deterministic business logic from AI-generated explanations.

Deterministic backend logic handles:

- system sizing
- savings estimation
- investment estimation
- subsidy assumptions
- payback calculation
- solar report generation

AI handles:

- explaining report values
- answering report-related questions
- retrieving platform knowledge
- supporting admin operational workflows
- summarizing controlled operational data

This separation improves reliability because important calculations remain controlled and auditable.

## AI Ops Retrieval Scope

The AI Ops RAG system can use knowledge base documents to answer questions about:

- platform overview
- AI Advisor design
- AI Explainer design
- lead workflow
- Azure architecture
- solar report concepts
- operational workflows
- system boundaries

AI Ops should answer using retrieved knowledge where possible.

If the information is not available in the knowledge base or approved operational tools, the system should avoid inventing unsupported details.

## Important Notes

SwitchToSolar is not only a solar calculator.

It combines solar report generation, installer workflows, lead operations, AI guidance, and internal AI Ops tooling.

The platform is designed around controlled backend workflows, deterministic calculations, retrieval-grounded AI, and operational observability.
